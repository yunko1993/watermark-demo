# DOC 和 WPS 大文档水印限制样本

本目录中的 DOC 与 WPS 文件各包含 800 个独立正文段落和 30 张独立表格。表格单元格及分隔内容也会形成段落，因此重新读取时可以统计到 1043 个段落。

WPS 样本使用本项目支持的兼容口径：扩展名是 `.wps`，内部是 Word 97-2003 OLE2/DOC 二进制容器。它用于测试当前服务的 WPS 路由，不代表所有 WPS 历史私有格式。

上传任一文件后，分别点击“Aspose 下载”和“Spire 下载”，即可比较两个实现对超过 Free Spire.Doc 500 段落、25 张表格限制的处理结果。

下载后搜索 `LIMIT-CHECK-PARAGRAPH-0800` 和 `LIMIT-CHECK-TABLE-30`。Free Spire.Doc 14.3.1 在当前样本上会生成一个仍可打开的文件，但只保留前 500 个正文段落，两个终点标记都会缺失。
